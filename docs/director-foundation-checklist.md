# 短视频导演地基需求清单

最后更新：2026-04-22

## 目标

在推进代码实现前，先把“短视频导演视角”和“AI 出图工作流”需要的底层能力沉淀下来，避免后续只做出图功能，却缺少故事节奏、角色关系、道具一致性、参考图绑定和生成前检查。

本文件是需求地基，不代表所有能力都要第一轮暴露在 UI。策略是：

- 能力层先做加法，尽量完整。
- 默认 UI 保持简单。
- 高级控制渐进折叠。
- 真实使用后再做减法。

## Step 1：剧本 & 角色/背景设定台

### 必备产出

进入 Step 2 前，Step 1 应尽量产出：

- 整理后的剧本
- 剧本节奏/润色偏好
- 已确认角色
- 已确认背景场景
- 角色结构化属性
- 角色锁定词
- 角色参考图
- 背景场景参考图
- 关键道具列表
- 角色关系和剧情功能
- 可选：角色声音/台词气质，为 TTS 做准备

### 导演检查项

1. 故事钩子检查
   - 前 3 秒是否有悬念、冲突或视觉钩子。
   - AI 可给出：弱 / 中 / 强。
   - 示例建议：前 2 格先展示素描本和告白信，不要先交代背景。

2. 角色关系设定
   - 关系：暗恋 / 误会 / 对立 / 保护 / 利用。
   - 当前情绪：紧张 / 隐忍 / 怀疑 / 愧疚。
   - 剧情功能：主角 / 冲突触发者 / 秘密持有者 / 旁观者。

3. 声音和台词气质
   - 声音气质：清冷 / 少女感 / 低沉 / 温柔 / 疏离。
   - 语速：慢 / 标准 / 快。
   - 台词风格：克制 / 毒舌 / 直球 / 温柔。
   - 目的：为后续 TTS 和台词优化做准备。

4. 固定服装和关键道具
   - 固定服装：深色校服、白色衬衫等。
   - 关键道具：素描本、告白信、手机、刀剑、项链等。
   - 不可变化：发型、校服颜色、素描本外观。

5. 背景场景关系
   - 场景用途：对峙场景 / 告白揭示 / 悬疑氛围 / 转场空镜。
   - 可复用镜头：走廊、窗边、画架、门口。
   - 场景一致性：时间、天气、光线、道具是否统一。

6. 风格和尺度边界
   - 尺度：全年龄 / 成熟但不露骨 / 惊悚但不血腥。
   - 用于避免生成不可用图片，尤其是性感魅惑、惊悚、暴力、废土等题材。

### 进入 Step 2 前检查

建议在 Step 1 底部或顶部准备状态里显示：

- 钩子强度：强 / 中 / 弱
- 主要角色参考图：完整 / 缺失
- 背景场景参考图：完整 / 可选缺失
- 关键道具锁定：已锁定 / 未锁定
- 角色关系：完整 / 缺少关系
- TTS 预设：已设置 / 未设置

如果缺少主要角色参考图，不阻止进入 Step 2，但提示风险：

> 未生成主要角色参考图，后续分镜可能角色不一致。

## Step 2：分镜 & 出图

### 必备产出

Step 2 应从 Step 1 继承：

- 剧本
- 已确认角色
- 角色参考图
- 已确认背景场景
- 背景参考图
- 关键道具
- 风格和尺度边界
- 角色关系/剧情功能

每个分镜最好拥有：

- 场景描述
- 出场角色
- 台词
- 情绪
- 构图/镜头
- 预计时长
- 字幕位置
- 使用的角色参考图和强度
- 使用的背景参考图和强度
- 关键道具
- 单格局部反馈
- 版本历史

### 导演检查项

1. 镜头时长
   - 每格预计时长，例如 2.0s。
   - 是否有台词。
   - 是否适合 TTS。

2. 字幕位置和主体避让
   - 字幕位置：底部 / 中下 / 无字幕。
   - 主体避让：开启 / 关闭。
   - 避免角色脸和关键道具被字幕遮挡。

3. 镜头连续性
   - 动作是否连续。
   - 角色站位是否反了。
   - 道具位置是否一致。
   - 可后续引入 AI 连续性检查。

4. 角色参考绑定
   - 本格角色：林夏、顾言。
   - 使用参考图：林夏 75%，顾言 75%。
   - 主参考：林夏或顾言。
   - 多角色同框时避免特征融合或互换。

5. 道具锁定
   - 本格关键道具：素描本、告白信。
   - 道具一致性：开启 / 关闭。

6. 失败重试策略
   - 同 prompt 重试。
   - 增强角色一致性。
   - 降低参考强度。
   - 重写 prompt。

7. 批量生成前确认
   - 即将生成多少格。
   - 画幅/清晰度。
   - 使用哪些角色参考图。
   - 使用哪些背景参考图。
   - 预计消耗多少次图片生成。
   - 生成中会锁定哪些设置。

8. 生成队列状态
   - 队列中 / 生成中 / 成功 / 失败 / 已取消。
   - 后续可支持暂停/继续或停止后续生成。

9. 单格版本历史
   - v1 初版。
   - v2 加强表情。
   - v3 改低角度。
   - 用户可回退。

10. 封面候选
   - 可标记某格为封面候选。
   - 非第一轮必须，但应预留。

## 优先级建议

第一轮优先：

1. Step 1：故事钩子检查
2. Step 1：角色关系/剧情功能
3. Step 1：固定服装/关键道具
4. Step 1：角色声音/台词气质
5. Step 2：每格预计时长
6. Step 2：每格角色参考绑定
7. Step 2：关键道具锁定
8. Step 2：批量生成前确认
9. Step 2：失败重试策略
10. Step 2：单格版本历史

后续再做：

- 封面候选
- 暂停/继续队列
- AI 连续性检查
- 固定 seed
- 局部裁切
- 高级负面词编辑

## 专业导演层未来能力

以下能力从专业短剧导演/制片流程角度非常重要，但可以先进入需求文档，等主流程使用一段时间后再逐步加入。目标是避免产品只停留在“漂亮分镜图生成器”，而是逐步走向“短剧生成器”。

### 高优先级未来能力

1. 情绪曲线
   - 记录整条短剧的情绪推进，而不是只记录单格情绪。
   - 示例：开场悬念 -> 对峙升级 -> 短暂误会 -> 暧昧反转 -> 留白。
   - AI 可检查每 3-5 个镜头是否有情绪变化，避免整片太平。

2. 信息揭示节奏
   - 控制观众在第几格知道哪些信息。
   - 示例：
     - 第 1 格露出素描本。
     - 第 3 格露出告白信一角。
     - 第 5 格揭示“画的是顾言”。
   - 避免 AI 在开头一次性把秘密说完。

3. 表演指导
   - 给角色提供画面表演方向。
   - 字段可包括：微表情、肢体动作、表演尺度、禁止表情。
   - 示例：躲闪、强装冷静、攥紧本子、后退半步、不要大笑。

4. 每格 SFX/环境声
   - 除 TTS 外，为每格预留音效/环境声。
   - 示例：雨声、雷声、脚步声、纸张翻动、灯管闪烁、心跳低频。
   - 后续 Step 3 导出时可用于声音设计。

5. 成片时长预估
   - 批量生成前预估整条视频时长。
   - 每格时长累计后提示是否超出建议长度。
   - 同时展示预计生成耗时、图片生成次数和失败重试可能增加的成本。

6. 审核/合规边界强化
   - 在尺度边界基础上增加平台可发布性检查。
   - 关注：暴力血腥、未成年人性感化、名人脸/版权角色、过度恐怖、自残/违法暗示、平台敏感词。
   - 对“性感魅惑”等风格保持“成熟但不露骨”，避免未成年性感化。

7. 标题/封面钩子
   - 为发布环节预留标题和封面文案能力。
   - 可输出：标题、封面文案、3 个标题备选、标签、一句话简介。
   - Step 2 可标记封面候选图，Step 3 再生成发布信息。

8. 机位/站位连续性
   - 记录角色左右站位、视线方向、过肩镜头从谁背后拍。
   - 目标是避免 AI 出图时两人位置跳变，剪起来不连续。
   - 后续可引入 AI 连续性检查。

### 中优先级未来能力

1. 系列化/集数
   - 预留 episode 概念。
   - 记录本集标题、本集目标、上集回顾、下集钩子、长期设定、本集新增设定。
   - 适合后续做连续短剧。

2. BGM 情绪
   - 记录 BGM 情绪和节奏。
   - 示例：悬疑、浪漫、热血、悲伤；慢/中/快。
   - 爆点处是否压音乐，结尾是否留悬念音。

3. 素材资产库
   - 将角色图、背景图、道具图、分镜图沉淀为可复用资产。
   - 支持已弃用版本、下一集复用、资产状态管理。

4. 旁白/无对白/屏幕文字类型
   - 支持旁白、内心独白、无对白空镜、屏幕文字、手机聊天截图等镜头类型。
   - 这些镜头会影响画面构图、TTS 和字幕处理。

### 当前处理策略

- 以上能力先进入需求地基，不急于进入第一版 UI。
- 当前 MVP 仍优先打通：Step 1 设定准备 -> Step 2 分镜确认/出图 -> Step 3 导出。
- 后续使用一段时间后，根据真实痛点选择加入。
- 实现时优先以“检查卡/诊断卡”的方式低成本引入，而不是一开始做成复杂参数面板。

## 实现提醒

- 不要把所有能力直接平铺给用户。
- 默认只展示最关键的状态和按钮。
- 检查项可以先以只读诊断卡形式出现。
- 高级项放入抽屉、弹窗或“高级设置”折叠区。
- 任何会消耗图片生成次数的动作都应有明确按钮或确认。
